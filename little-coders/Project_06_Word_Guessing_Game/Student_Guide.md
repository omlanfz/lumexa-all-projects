# 🔤 Student Guide: Word Guessing Game

## What You're Building

A game where the computer secretly picks a word from a list, and you try to guess it within 5 attempts!

## How to Run It

1. Open `word_guessing_game.py` in Thonny.
2. Press the green Run button.
3. Type your guess for the secret word.
4. Keep guessing until you get it right, or you run out of attempts!
5. Choose to play again or stop.

## Try This

- Play until you win, and notice the word changes each time you play again — that's the `random` module picking a new secret word.
- Open the code and add 2 or 3 of your own words to the `word_list` — just remember to put quotes around each word and a comma between them.
- Try changing `max_attempts` to a different number, like 3 or 8, and see how it changes the game's difficulty.

## Why Guess the Whole Word?

We built this game so you guess the WHOLE secret word instead of letter-by-letter, because it's simpler and lets us use exactly what we've learned so far: lists, the `random` module, loops, and if/else. Maybe one day you'll build a letter-by-letter version too!
