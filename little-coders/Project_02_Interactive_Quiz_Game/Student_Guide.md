# 🚀 Student Guide — Quizzy's Space Quiz

## Welcome!

Open `project.sb3`, click the green flag, and answer Quizzy's 5 questions by typing your answer and pressing Enter!

## 🎮 Game Challenge

Try to get all 5 questions right and see your final score — can you get 5 out of 5?

## 🧠 Think Like a Coder

Every question follows the same recipe:
1. Quizzy asks a question and waits for your answer.
2. Scratch checks: does your answer EXACTLY match the correct one?
3. If yes — celebration! Score goes up by 1.
4. If no — a gentle "good try" message shows the right answer.

## 🎨 Make It Yours

Open the code and try:
1. Changing one of the questions to something you'd like to ask a friend.
2. Adding a 6th question of your own, following the same ask/check/celebrate pattern.
3. Changing the celebration message or sound for correct answers.

## 🔍 Debug Detective

If you type "RED" in capital letters for the Mars question, does it still count as correct? Try it! Scratch usually ignores capital vs lowercase letters, but it still needs the SAME word — try typing "reed" instead and see what happens.

## 🏆 Victory Moment

After you finish all 5 questions, Quizzy shows your final score with a fanfare. However many you got right, you just built (and played) a real coded quiz game — great job, space coder!
