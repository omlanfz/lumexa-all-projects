# Project Overview — Creative Music Maker

## Theme
A playful sound-studio where clicking or pressing keys triggers different instruments, each with its own pitch and a satisfying visual pulse — the Course 10 portfolio piece that shows off events, sound, and looks working together for creative expression.

## Instruments
| Sprite | Key | Shape/Color | Sound(s) |
|---|---|---|---|
| Drum | 1 | Red circle | Low thump (220 Hz) |
| Bell | 2 | Yellow star | Bright ring (880 Hz) |
| Xylo | 3 | Teal rectangle | 3-note rising run (523/659/784 Hz) |
| Bass | 4 | Blue triangle | Deep note (110 Hz) |
| Chime | 5 | Purple star | 2-note shimmer (1046/1318 Hz) |

## Visual Feedback
Each instrument, when triggered, switches to a bright "pulse" costume and grows by 25 size while its note(s) play, then shrinks back to normal size and its regular costume — so every sound is paired with something satisfying to see, not just hear.

## Learning Concepts Demonstrated
- `when this sprite clicked` and `when key pressed` both triggering the SAME behavior
- `play sound until done` sequencing multiple notes in a row for the Xylo and Chime
- `change size by` / `set size to` for a "pulse" visual effect
- Multiple independent sprites each with their own self-contained event-driven behavior
