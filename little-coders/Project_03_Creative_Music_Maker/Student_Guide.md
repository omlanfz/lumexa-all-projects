# 🚀 Student Guide — Lumexa Sound Studio

## Welcome!

Open `project.sb3` and click the green flag. Then click on any instrument — or press the number keys 1 through 5 — to make music!

## 🎮 Try This

- Press **1** for the Drum, **2** for the Bell, **3** for the Xylo, **4** for the Bass, **5** for the Chime.
- Click directly on any instrument sprite to hear the same sound.
- Notice how each instrument PULSES bigger and changes color when it plays!

## 🎨 Make It Yours

1. Try clicking instruments in different orders to "compose" your own little tune.
2. Open the code for one instrument and change its pitch by editing the sound in the Sounds tab, or add a brand-new note.
3. Add a 6th instrument sprite of your own, with its own key, sound, and pulse effect — copy the pattern you see in the other instruments!

## 🧠 Think Like a Coder

Notice each instrument has TWO event scripts that do the exact same thing: one starts with "when this sprite clicked," and the other starts with "when key pressed." That's two different doorbells ringing the same bell inside!

## 🔍 Debug Detective

If you wanted the Xylo to play its 3 notes in a row but SKIP waiting for each one to finish, which block would you swap "play sound until done" for? (Hint: try "play sound" instead and see how the notes overlap!)

## 🏆 Victory Moment

You just built a real interactive instrument — one that reacts to clicks AND key presses, with both sound and visual feedback. That's exactly what real music apps do! Great job, sound coder. 🎵
