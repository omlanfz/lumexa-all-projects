# Teacher Guide — Project 03: Creative Music Maker

## Purpose
This project reinforces Lesson 3 (looks/sound) and Lesson 4 (events) in a joyful, low-pressure creative context — there's no "winning," just composing.

## How to Use in Class
1. Let students explore freely first — click around, press number keys 1–5, and just enjoy the sounds and pulses.
2. Open one instrument's code (e.g., Bell) and show that BOTH a click event and a key-press event trigger the exact same set of blocks — a great example of "two doorbells, one script."
3. Point out the Xylo and Chime sprites play more than one note in a row using several `play sound until done` blocks back to back — ask students to predict what would happen if `play sound` (without "until done") were used instead.
4. Discuss the "pulse" effect: size goes up, then back down — connect to Lesson 3's `change size by` / `set size to` blocks.

## Key Teaching Moments
- **Same event, same reaction:** clicking and key-pressing calling identical code shows students code can be reused for multiple triggers.
- **Visual + audio together:** the pulse effect makes the sound feel more alive — a good discussion starter about "juice" (making digital things feel satisfying).
- **Composing = experimenting:** there is no wrong way to play this project, which is a nice contrast to the quiz game's right/wrong answers.

## Discussion Questions
- "Why do you think each instrument shrinks back to its normal size after pulsing?"
- "What would happen if you removed the 'set size to 100' block — try it and see!"
- "Can you make up a little rhythm or tune using just the number keys 1–5?"
