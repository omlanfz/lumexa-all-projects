# 🧠 Student Guide: Personal Quiz App

## What You're Building

A quiz game that asks for your name, asks you 5 fun questions, keeps score, and gives you a friendly message at the end based on how you did!

## How to Run It

1. Open `personal_quiz_app.py` in Thonny.
2. Press the green Run button.
3. Type your name and press Enter.
4. Answer each question when asked.
5. See your final score and message!

## Try This

- Run it once and try to get a perfect score.
- Run it again and answer on purpose incorrectly — see how the message changes.
- Open the code and change Question 1's answer check (currently "green") to a different question of your choice.
- Add your own 6th question! Copy the pattern of an existing question, change the question text and the correct answer, and don't forget to add `score = score + 1` inside the `if` block.

## What to Watch For

- `input()` always gives text, so number answers like "8" need to be compared as `"8"` in quotes.
- Every `if` needs a matching `:` and indented code underneath.
- Have fun and make it your own!
