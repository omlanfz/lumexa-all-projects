## Filled Example — Jordan R.

| Section | Jordan's Answer |
|---|---|
| **Project Name** | Habit Tracker — a browser-based app for logging a daily habit and seeing a streak count. |
| **Problem / Goal** | I wanted a simple way to track drinking water daily, but wanted to build my own instead of using an existing app, so I could understand the logic myself. |
| **Tools Used** | HTML, CSS, JavaScript (localStorage). |
| **My Approach** | Built the layout in HTML/CSS first. Used JavaScript to save each day's entry in the browser's localStorage so the data survives a page refresh. Added a function that checks for consecutive days logged and displays a streak count. |
| **Result** | It works — data saves correctly and the streak count updates properly. It only works on one browser/device right now; it doesn't sync across devices, which I know is a limitation. |
| **What I Learned** | I learned how localStorage works and why it's fine for a single-device app but not enough for something that needs to sync — that would need a real backend and database, which I want to learn next. |
| **Link / Screenshot** | Link: jordanbuilds.dev/habit-tracker |
