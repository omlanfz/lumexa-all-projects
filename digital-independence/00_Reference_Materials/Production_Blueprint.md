# Production Blueprint — All 24 Lessons

Each lesson package = Instructor_Guide.pdf + Student_Lesson.pdf + Worksheet.pdf (+ project
files / simulation resources where noted). Building course-by-course; Course 16 is being
built first end-to-end (this delivery), Course 17 and 18 follow the same pattern next.
