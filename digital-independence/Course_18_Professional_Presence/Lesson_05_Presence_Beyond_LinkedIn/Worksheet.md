# Worksheet: Presence Beyond LinkedIn

Use this worksheet to plan how you'll strengthen your professional presence using channels beyond LinkedIn. Remember: your portfolio site is your foundation, and every other channel should reinforce it, not replace it.

## Filled Example: Alex T., age 15 (portfolio-first)

| Channel | Why it fits me | Next action |
|---|---|---|
| Portfolio site (primary) | I already have real projects built (chess-timer app, shelter sign-up page) — this is where all my proof lives | Add a "Notes" section with 2 entries this week |
| School showcase / competition | My school runs a community-impact tech fair every fall, and my shelter project fits the theme | Submit the shelter sign-up project to the tech fair by Sept 20 |
| Community project board | My class already uses a shared GitHub organization for projects | Upload both projects to the class GitHub org by this Friday |

**Reflection (Alex's example):** "My portfolio site shows what I've built, but on its own it's just my word. Getting the shelter project into the school tech fair means someone else — the judges — will vouch for it too, and putting it on the class GitHub means my teacher and classmates can find it without me sending a link. Each channel backs up the others: the site is the proof, the showcase is the outside recognition, and the project board makes it easy for people at school to actually see it."
