# Course 17 — Student Guide: Skills That Pay

## What This Course Is
Over 8 classes, you'll turn a real skill from your Course 16 portfolio into a priced,
scoped service — and run a full simulated client project from first inquiry to final handoff.

## What You'll Walk Away With
- A professional service package
- A pricing worksheet
- A proposal + client/project brief
- A completed simulated client project (a strong new portfolio case study!)

## Ground Rules
- We never bypass age requirements or misrepresent our age to use any platform.
- A written agreement template we use in class is for practice — it is not a real legal
  contract.
- Any real paid client work should involve a parent or guardian.

## How the 8 Lessons Fit Together
1–2: Understand the freelance landscape and turn your skill into a real service.
3–4: Package and price that service.
5–6: Learn safe, realistic ways to find opportunities and how platforms differ by age.
7: Learn to write proposals and communicate like a professional.
8: Run a complete, safe, simulated client project — start to finish.
