# Revision Request — Handling Instructions

The `Client_Feedback.md` message contains one concrete revision request: **move the Events
section higher on the page, right after the intro.**

## Is this scope creep or a reasonable revision?
This is a **reasonable revision** — it's a layout/ordering change within the same page and
feature set already scoped, not a new feature. Students should be able to explain why (in
their documentation) this is different from, say, "actually, can you also build us a members
login system" (which WOULD be scope creep, requiring a new proposal/price).

## Student Task
1. Make the change (reorder the sections).
2. Write a 2–3 sentence note documenting what changed and why it stayed within scope.
3. Reply to the client with a short, professional message confirming the change is done.
