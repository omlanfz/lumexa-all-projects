### Filled Example — Fictional "Jordan R." → Career Compass Club
- **Understanding of Need:** Priya needs one simple webpage so the club stops relying on a
  group chat — it should explain the club, list upcoming events near the top, and give
  interested students a way to reach out.
- **My Approach:** Build a single-page HTML/CSS site (reusing my Course 16 portfolio skills),
  with the Events section placed prominently, deployed for free via GitHub + Vercel.
- **Included:** About section · Events list (client-editable via a simple text file) · Contact
  link · Free deployment
- **Not Included:** Ongoing event updates after handoff (client will edit this herself)
- **Price:** $90 (practice estimate, simulated — not a real transaction)
- **Timeline:** 2 weeks
- **Next Steps:** "Once you approve, I'll start building and check in halfway through with a
  draft link."
