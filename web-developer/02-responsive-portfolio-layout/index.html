About

I'm a student developer who enjoys the puzzle of turning a design idea into working code — balancing layout, color, typography, and performance until a page feels effortless to use. My favorite part of any project is the responsive pass: making one layout work beautifully everywhere from a phone to a wide monitor.

When I'm not coding, I'm usually sketching UI concepts or reading about accessibility best practices — I believe a well-built website should work for everyone, not just the "average" visitor.
